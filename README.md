The Lite edition is released under the MIT License. The commercial Full edition is available separately on Agensi.io under its applicable purchase terms.

## Install QS Bid Review Suite Lite for free

Run inside Claude Code:

```text
/plugin marketplace add paulfan-windia/windia-skills
/plugin install windia-qs-lite@windia-skills
/windia-qs-lite:windia-qs-lite
```

For supported standalone clients, download the [Lite ZIP](downloads/windia-qs-lite-1.0.1.zip) or [Lite .skill installer](downloads/windia-qs-lite-1.0.1.skill). Both contain the same free Lite skill.

Provide your tender instructions, evaluation criteria, appointment or contract, BOQ and written addenda. Then ask:

```text
Use WINDIA QS Bid Review Suite Lite to check these tender documents.
Identify the project boundary, effective revisions, missing information,
key contractual questions and next review actions.
Return a one-page review brief with precise source references.
```

Read the [QS Lite guide and Lite / Full comparison](docs/qs-lite.md) for the worked example, scope and platform instructions.
