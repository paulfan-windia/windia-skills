# Fictional intake example

A developer requests a first-pass review of a common-area finishes tender. The package lists a typical lobby plan, reflected ceiling plan and finish schedule. Corridor elevations and the door-opening deduction rule are still to be confirmed.

**Preliminary intake** — Record plan and schedule revisions and whether each drawing is approved for tender. Mark corridor elevations and the measurement basis as outstanding.

**Draft scope** — Set up headings for floor finishes, wall finishes, ceilings and trims. Assign each heading a drawing reference field, location, unit and status. Split apartment corridors from lift/elevator lobbies and stair lobbies where finishes differ.

**Queries before measurement** — Ask whether repeated plans represent mirrored layouts or actual additional units and whether threshold strips fall under floor finishes. Refer opening deductions and fixture scope to the project reviewer.

**Result** — A drawing register, a blank BOQ outline and a review-action list are ready for the QS. Calculation cells and rates remain blank.
