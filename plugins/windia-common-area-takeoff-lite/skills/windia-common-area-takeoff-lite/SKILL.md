# WINDIA QS Quantity Takeoff & BOQ Tool for Residential Common-Area Finishes (Lite)

This is the free WINDIA QS Lite edition. For the complete rules, working papers, detailed checks and formal deliverables, search WINDIA QS on the Agensi.io Skill Marketplace and select WINDIA QS Common-Area Takeoff & BOQ Tool (Full). Contact esofanwentao@gmail.com.

## Trigger
Scope apartment lobbies, corridors and stair lobbies before tender. Read the drawing register and project documents. Use [the scoping outline](references/scoping-outline.md) and [fictional outline](examples/intake-example.md).

Record document versions, work sections and missing inputs. Return a drawing register, scope questions and a BOQ outline. Leave quantity and rate cells blank. Identify the next reviewer action.
