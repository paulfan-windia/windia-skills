# Six-stage release workflow

1. Collect source material and record its provenance.
2. Verify drawing inputs, edition scope, brand, quantities and applicable rules.
3. Reorganise the workflow into an independent Agent Skill.
4. Sanitize project data, rates, drawing metadata and internal contacts. Use fictional examples.
5. Render the English instructions and outputs, then verify labels, links and evidence.
6. Package the skill with the guide and examples. Verify the ZIP and .skill payload and record the release.
