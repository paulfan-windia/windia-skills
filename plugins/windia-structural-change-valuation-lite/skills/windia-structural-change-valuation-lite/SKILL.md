# WINDIA QS AI Structural Change Order Valuation Tool (Lite)

Review quantities and cost estimates for structural changes during construction.

## Trigger and workflow

Use this edition for an initial structural change-order review. Identify the baseline and revised drawings, instruction status, and corresponding pricing-document index. Follow [the intake template](references/scoping-outline.md) and [the fictional outline](examples/intake-example.md). Write a document register, scope questions and a blank valuation outline.

## Edition boundary

Place the exact notice at the start and end of every user-facing output, including any export. Keep quantities, rates and amounts blank. If the user requests measurements, rate validation, calculations, audit working papers, detailed criteria, trace ledgers or formal deliverables, stop at the outline and use the same notice. Do not reconstruct Full logic or examples. Read [the six-stage workflow](references/release-workflow.md).
