# Six-stage release workflow

1. Collect source materials and record revision and provenance.
2. Verify scope, instruction status, quantities, rates, and authority.
3. Reorganise inputs and outputs into an independent Agent Skill.
4. Sanitize live records. Use fictional drawings, rates and source identifiers.
5. Render English outputs and review layout, calculations and source links.
6. Package the Skill and record its version, verification and release evidence.
