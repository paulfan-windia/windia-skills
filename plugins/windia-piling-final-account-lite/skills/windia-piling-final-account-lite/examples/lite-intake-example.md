# See it in action - Lite (synthetic)

## Request

I am closing out a warehouse piling package. The submitted pile schedule, the latest layout and the installation records show different coverage. Help me organise the first review and tell me which documents to request.

## Result

**Scope.** Confirm the supported driven pile families and the relevant work areas, then freeze the submitted account, latest approved pile layout and installation log versions.

**Input requests.** Request the signed BOQ measurement basis, site records for unmatched piles, the cap detail and project datum, and a reliable record of any trimming, drive-down, splice or weld evidence. Ask who can approve changes to the submitted account.

**First-pass outline.** Set up a document checklist, a scope and exclusions note, candidate issues for possible duplicate or missing pile IDs, and a handoff note for the quantity surveyor. Preserve the source name and locator wherever the materials already provide one. Flag the cutoff basis and revisions for professional review.

**Deliverable.** A preliminary intake brief with an outline for a review workbook. The account quantities and proposed adjustments remain open for the detailed review.
