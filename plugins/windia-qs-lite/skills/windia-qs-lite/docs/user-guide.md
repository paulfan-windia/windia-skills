# WINDIA QS Lite user guide

This is the free Lite edition. For the Full edition, [search](https://agensi.io/) the Agensi.io Skill Marketplace for **Skill WINDIA QS Tender Review Suite (Full)**. Contact [esofanwentao@gmail.com](mailto:esofanwentao@gmail.com).

Install the Lite ZIP in Claude Customize > Skills and enable it, or install the published GitHub plugin through Claude Code. In eligible ChatGPT workspaces, upload the ZIP from Plugins > Skills > Create. Provide the current tender documents and ask for a one-page intake and review brief.

Identify the project, package, intended decision, source versions, missing documents and important conditions. Lite returns the brief using the supplied template and a short list of next actions. Review each finding against the original clause or schedule. Keep the actual issue status visible.

For Claude Code, after publication, run `/plugin marketplace add paulfan-windia/windia-skills` then `/plugin install windia-qs-lite@windia-skills`. Invoke `/windia-qs-lite:windia-qs-lite`.
