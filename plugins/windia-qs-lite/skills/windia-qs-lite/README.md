WINDIA QS Bid Review Suite (Lite) helps quantity surveyors, tender teams and engineering consultants check their inputs, identify early issues and prepare a concise review brief. It is free and open source under the MIT licence.

## Start with your tender evidence

Provide the current tender instructions, evaluation criteria, proposed appointment or contract, BOQ and written addenda. Lite produces a source checklist, a focused issue list and a one-page brief with an outline for the next stage. Every issue carries its source, consequence and requested next action.

## Install through the GitHub plugin marketplace

Run these commands inside Claude Code:

```text
/plugin marketplace add paulfan-windia/windia-skills
/plugin install windia-qs-lite@windia-skills
```

Invoke the installed skill:

```text
/windia-qs-lite:windia-qs-lite
```

Then provide the project files and ask:

```text
Use WINDIA QS Bid Review Suite Lite to check these tender documents.
Identify the project boundary, effective revisions, missing information,
key contractual questions and the next review actions.
Return a one-page review brief with precise source references.
```

## A worked example

A synthetic addendum changes a review period from 15 to 12 working days. The written starting event and deliverables remain applicable. Lite identifies the changed duration and the surviving conditions in the review brief, with the source references. Full adds the linked programme, contract and response records, an independent quantity check, and the seven-chapter sample proposal.
