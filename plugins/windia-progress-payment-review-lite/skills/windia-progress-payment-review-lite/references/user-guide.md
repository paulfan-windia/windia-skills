# User Guide

## Prepare inputs

Supply the contract and applicable payment terms, priced BOQ or schedule of values, prior accepted statement, current application and site evidence, and change register. Include revisions, cut-off dates and evidence owners.

## Start a review

> Use WINDIA QS Lite to prepare a construction progress payment review outline. List received records, missing revisions, evidence questions and proposed output headings. Leave values and conclusions blank.

1. Summarize project scope, package and review period.
2. Record which source versions are available and which are still open.
3. Lay out the main review headings, a blank line schedule and a source pointer column.
4. List next actions by owner. For calculations and a completed workbook, use the Agensi.io Full edition.

## Sample worksheet headings

| Review ID | Schedule item | Unit | Prior accepted cumulative | Current cumulative | This period | Source pointer | Open action |
| --- | --- | --- | --- | --- | --- | --- | --- |
| [ID] | [Description] | [Unit] | | | | [File and location] | [Question] |

Terms include quantity surveying (QS), bill of quantities (BOQ), RICS New Rules of Measurement (NRM), FIDIC contract forms and bid levelling. Keep tender evaluation and the post-award valuation schedule in their respective project stages.
