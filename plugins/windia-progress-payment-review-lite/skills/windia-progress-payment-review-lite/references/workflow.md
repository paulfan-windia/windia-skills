# Six-step workflow

1. **Receive source documents.** Create a register for the signed contract, schedules, applications, inspection evidence and approved changes.
2. **Proofread.** Confirm revisions, dates, completeness and overlapping scope. Flag uncertain records.
3. **Restructure.** Separate the prior accepted period, current cut-off and current-period review. Use stable line and document IDs.
4. **Review confidentiality and redact.** Use authorized project inputs. Replace all client, site and rate information with synthetic data for external examples. Inspect workbook metadata and embedded sources before sharing.
5. **Render.** Produce the deliverables allowed by the edition. Keep unsupported items visible.
6. **Capture the Skill baseline.** Save the edition, version, source schema, validation results, example fixtures and publication receipt. Re-test against the contract basis on each new project.
