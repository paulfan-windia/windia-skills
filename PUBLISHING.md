# Publishing and maintenance

This public repository contains WINDIA QS Lite under the MIT licence. The Claude Code marketplace name is `windia-skills`; the plugin name is `windia-qs-lite`.

The Full suite is distributed separately through Agensi.io for USD 9.99 as a one-time purchase. Search Agensi.io for **Skill WINDIA QS Tender Review Suite (Full)**. The Full product URL placeholder remains `AGENSI_PRODUCT_URL` until a live listing is verified.

Update the marketplace version, plugin version, skill version and standalone downloads together for future releases. Keep Full commercial materials and internal management records outside this repository.

Contact esofanwentao@gmail.com.

## Product matrix maintenance

Update `catalog/products.json` only from verified product information. Run `python3 scripts/update-catalog.py` before committing, or allow the catalog workflow to regenerate README.md and CATALOG.md after a metadata update. Keep historical verification dates for unchanged records. Add future marketplace plugins without removing existing entries.
