# WINDIA QS Construction Bid Comparison Tool (Lite)

Organize construction bid submissions, flag missing information, and create a preliminary bid comparison outline.

**Version 1.0.0 · Free · MIT**

## Install

In Claude Code:

```text
/plugin marketplace add paulfan-windia/windia-skills
/plugin install windia-bid-levelling-lite@windia-skills
/windia-bid-levelling-lite:windia-bid-levelling-lite
```

If the marketplace is already registered, run `/plugin marketplace update windia-skills` before installing.

For compatible standalone clients, download the [ZIP](../downloads/windia-bid-levelling-lite-1.0.0.zip) or the [.skill installer](../downloads/windia-bid-levelling-lite-1.0.0.skill). See the [user guide](../plugins/windia-bid-levelling-lite/skills/windia-bid-levelling-lite/docs/user-guide.md) and the [example outline](../plugins/windia-bid-levelling-lite/skills/windia-bid-levelling-lite/examples/template-skeleton.md).

## Agensi

- [Lite on Agensi](https://agensi.io/skills/windia-qs-construction-bid-comparison-tool-lite) is free.
- [WINDIA QS Construction Bid Comparison Tool (Full)](https://agensi.io/skills/windia-qs-construction-bid-comparison-tool-full) is available on Agensi for USD 19.99 one-time. Full provides detailed quantity and commercial checks, clarification tracking, and a source-linked review report.

**Bid Leveling** is the process of comparing construction bids on a common basis. Lite organizes intake and prepares an outline for review.
